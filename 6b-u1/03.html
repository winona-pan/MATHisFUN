公式怎麼來

分配律

用一個長方形的面積，看懂 (a + b) × c = a × c + b × c。

1一塊地，兩種算法

2公式怎麼來

① 整塊長方形：長 (a + b)、寬 c → 面積 = (a + b) × c。

② 切成兩塊：藍色 a × c、橘色 b × c → 面積 = a × c + b × c。

③ 同一塊地，面積當然一樣！所以 (a + b) × c = a × c + b × c，叫做分配律（c 分給 a 和 b 各乘一次）。

④ 減法也可以：(a − b) × c = a × c − b × c（大塊減掉切掉的那塊）。

⑤ 反過來用最常見：3.6 × 7 + 6.4 × 7 = (3.6 + 6.4) × 7 = 10 × 7 = 70。

公式
(a + b) × c = a × c + b × c
(a − b) × c = a × c − b × c
從左到右叫「拆開」，從右到左叫「提出來」
⚠️

c 要兩個都乘到！常見錯誤：(5 + 3) × 4 寫成 5 × 4 + 3 = 23（漏乘 3 × 4）。

🎒 國中預告

國中叫做「展開」：3(x + 2) = 3x + 6，反過來叫「提公因式」：5x + 5y = 5(x + y)。全部都是分配律！
