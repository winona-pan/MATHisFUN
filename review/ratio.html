比與比值

比例尺就是一種「比」。先複習比、比值、相等的比。

1紅球和藍球

比（紅 : 藍）
比值 = 前項 ÷ 後項
最簡整數比

2想一想

比：2 個紅、3 個藍 → 紅 : 藍 = 2 : 3。前面的 2 叫前項，後面的 3 叫後項。

比值：前項 ÷ 後項 = 2 ÷ 3 = ⅔。

按「每一組都 ×2」：變成 4 : 6，可是紅藍的樣子沒變（還是每 2 紅配 3 藍），比值也還是 ⅔。

所以：前項、後項同乘（或同除）一個數，比值不變，叫做相等的比。4 : 6 = 2 : 3。

記起來
a : b 的比值 = a ÷ b
前後項同乘、同除 → 相等的比

🎒 國中預告

國中會學「比例式」：a : b = c : d 時，a × d = b × c（內項乘積 = 外項乘積），可以用來求 □。
